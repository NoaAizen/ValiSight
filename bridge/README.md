# N6 → Jetson bridge

מעביר את פריימי המצלמות (תרמי + RGB) ואת דגימות ה-IMU מלוח ה-N6 אל הג'ייסון
דרך ה-USB, בפורמט בינארי עם מספר רץ, חותמת זמן ו-CRC לכל הודעה — כדי שההיתוך
על הג'ייסון (ושכבת ה-IMU של יעל) יקבלו נתונים שאפשר לסמוך עליהם, וכל אובדן
ייספר במקום להיעלם בשקט.

| קובץ | תפקיד |
|---|---|
| `bridge_protocol.h` | **החוזה** — מבנה ההודעה, לצד ה-C |
| `bridge_protocol.py` | אותו חוזה לפייתון (רץ גם על ה-N6 וגם במחשב) + `Decoder` |
| `n6_bridge_tx.py` | השולח — רץ **על ה-N6**. `Bridge` = ליבה בלי חומרה, `main()` = החיבור לחיישנים |
| `n6_bridge_start.py` | משגר — דוחף את השולח ל-N6 (raw REPL). עם `--record` גם מקליט ומדפיס סטטיסטיקה |
| `bridge_rx.c` | המקלט — רץ **על הג'ייסון** ב-C. פותח לקריאה בלבד, לא משדר לעולם |
| `test_*.py` | בדיקות: חוזה, שולח, מקלט (pty + קובץ, גם בבניית ASan) |

## הרצה
```
make test                                   # בונה + כל הבדיקות, בלי חומרה
python3 n6_bridge_start.py --record s.bin --seconds 10   # בדיקה חיה + הקלטה
./bridge_rx s.bin -o out/                   # replay ההקלטה במקלט ה-C
python3 n6_bridge_start.py && ./bridge_rx /dev/serial/by-id/usb-MicroPython_Pyboard* -o out/   # חי
```
`out/` יכיל `<seq>_thermal.bin` / `<seq>_rgb.bin` (הנתונים כפי שנשלחו) ו-`imu.csv`
עם חותמות זמן **פרוסות** (בלי גלישה).

## מה עוד לא
- חותמת הזמן היא `ticks_us` (גולשת כל 17.9 דק'; המקלט פורש). המעבר ל-TIM2 = שינוי `ts_src` בלבד.
- IMU נדגם פעם אחת לכל פריים תרמי (~9 Hz). לקצב גבוה — דגימה מטיימר לחוצץ טבעתי (v2).
- מסירה חיה להיתוך (socket / shared memory) — כרגע המקלט כותב לדיסק.
- ה-N6 יכול להיות תפוס ע"י תצוגה אחרת (`fuser /dev/ttyACM0`) — רק תהליך אחד קורא מהיציאה.
