Open issues

  • Thermal segment sync — horizontal white bands land on the same rows in every frame, so this is systematic rather than random packet loss. A Lepton 3.x sends four segments per frame; the image is real but the segments are not assembling cleanly.
  • Radiometry returns sentinels — the mode flips on and GET_RADIOMETRY reports 1, but FPA reads −167.78 °C and AUX reads −273.15 °C. Treat thermal frames as relative intensity, not temperature.
  • Stock radar config — the run used a standard TI profile, not the project’s tuned .cfg. Classification thresholds are calibrated for that file, so these labels demonstrate the pipeline rather than measure the scene.
  • RGB underexposed — the frame is valid but dim; auto-exposure needs a longer settle than the 1.5 s used here.
