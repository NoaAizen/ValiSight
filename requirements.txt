# rasterio backs DemSampler, so every priors run needs it, not only the
# terrain helpers. numpy is needed by the bulk DEM sampler behind the skyline
# march and by the IMU calibration solver. Both were reaching the environment
# as transitive installs; a consumer installing from this file alone got
# neither, and the stage failed at the point where the map looks at fault
# rather than the install.

# Data dependency, not installable via pip.
#
# PROJ needs the EGM2008 vertical shift grid to transform EPSG:4979 -> EPSG:3855.
# Without it PROJ silently degrades to a ballpark transform that returns the
# input height unchanged, so GeoidStage refuses to run. Fetch it once into
# data/ (gitignored, ~77MB):
#
#   curl -o data/us_nga_egm08_25.tif https://cdn.proj.org/us_nga_egm08_25.tif
#
# PROJ reads GeoTIFF (.tif) and legacy .gtx grids only. GeographicLib .pgm
# distributions of EGM2008 are not readable by PROJ.
